# Communication Style

How the operator wants the AI to respond. Format, voice, structure — not
what to say, but how to say it.

## What to include

- **Response format** — bullets vs prose, headers vs flat, code blocks vs inline
- **Length preference** — brevity vs thoroughness; when each is appropriate
- **Voice / tone** — casual vs formal, direct vs diplomatic, humorous vs neutral
- **What to avoid** — hedging, caveats, repetition, marketing language, em-dashes, etc.
- **Confidence signals** — how to flag uncertainty (e.g., "say 'I don't know' rather than guess")

## Example sections

```
## Preferred response format
- Bullets over prose
- Headers when multiple sections
- Lead with the answer, not the buildup

## Directness
- Direct answers; surface counterpoints only when meaningfully different
- Flag uncertainty; never fill gaps with plausible-sounding fiction

## What to avoid
- Verbosity (say it in half the words)
- Reflexive caveats ("it depends," "on the other hand")
```

This file is read by the AI on every session — small wording changes here
have a big cumulative effect.
